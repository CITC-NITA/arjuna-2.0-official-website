# Arjuna 2.0 Hackathon Website

The official website for Arjuna 2.0 Hackathon, organized by the Civil Innovation and Technology Cell (CITC), NIT Agartala. The platform was developed to provide participants with a seamless registration experience while serving as a central hub for hackathon information, announcements, schedules, and updates.

## Live Website

Website Link - [https://arjuna2.netlify.app/
](https://arjuna-2-0-official-website.vercel.app/)
## Features

- Online registration system for hackathon participants
- Responsive design optimized for desktop, tablet, and mobile devices
- Secure handling and storage of participant information
- Client-side and server-side form validation
- Event information, timelines, rules, and updates
- Clean and intuitive user interface for improved user experience
- Database integration for managing registration data efficiently

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB

## Project Overview

Arjuna 2.0 is a hackathon organized by the Civil Innovation and Technology Cell (CITC), NIT Agartala. This website was designed and developed to streamline the registration process and provide participants with all necessary event-related information in one place.

The frontend was built using React.js to create a fast, interactive, and responsive user experience. The backend was developed using Node.js and Express.js to handle user registrations, validation, and communication with the database. MongoDB was used to securely store participant information and manage registration records.

The project focused on usability, responsiveness, and reliability, ensuring that participants could easily access information and complete registrations across different devices.
